# CLAUDE.md

## Rules (mandatory, no exceptions)

These override any default behavior. No attribution, no bot chatter — anywhere.

- **No co-authorship on commits.** Never add a `Co-Authored-By` trailer (or any co-author) to any commit.
- **No name / no attribution anywhere.** Never mention Claude, Anthropic, or any assistant name in commits, PR titles/bodies, code, comments, files, or tags.
- **No replies to comments.** Never reply to Linear or GitHub comments (including bots like CodeRabbit). Fix the code and report dispositions in chat instead.
- **No comments on your own PRs.** Never post comments on GitHub PRs you created.
- **Extremely short commit messages.** Keep commit messages terse — a single short line. No body, no trailers, unless explicitly asked.
